总结

​	(1).三个模型在细长结构方面，Unet、DeepLabv3plus表现较好。我认为训练次数够多的情况下，这两个模型都会取得不错的效果。  ------------>>> 增加100轮次后，三个模型在细长结构上取得明显效果，其中DeepLabV3Plus表现最好，断开最少。其次是PSNNet，最后是Unet  ------->>> 为什么Unet反而比PSPNet变差了呢？------->>>  在保留图像细节信息的方法层面上，Unet的转置卷积+跳跃连接优于金字塔池化。对于小目标物体Unet更具有优势

​	(2).三个模型中在边界方面上，DeepLatv3Plus表现最好，既不会过于边界锯齿，也不会过于边界圆滑。----------->>>  增加100轮次后，DeepLatV3Plus最优，效果一致。PSPNet效果过于圆滑，Unet表现为边界锯齿  。 三个模型中DeepLabPlusV3的Boundary_F1最高，Unet其次，PSP最后。---------------->>>> 棋盘重影问题，卷积核大小与转置卷积不匹配  ------------------>>>  解决方法：采用别的上采样方式：1.最近邻插值，双线性插值。此外对于PSPNet过于圆滑的问题是该模型采用双线性插值方法进行上采样，该采样方法不带可学习的参数。而Unet的转置卷积待用可学习参数，只不过易出现棋盘重影问题



​	(3).三个模型中，DeepLabv3Plus对小目标的检测效果最好。我认为当训练次数增大情况下，DeepLabv3plus会取得不错效果。--------->>>当增加100轮次后，DeepLabPluas在小目标物体上反而更差，直接丢失目标。三个模型都存在此问题。为什么？？？  --------->>> Unet模型之所以会丢失小目标物体是因为下采样会丢失小目标物体，而跳转连接弥补不了小目标信息的恢复。DeepLabv3puas丢失小目标是因为放大了"类别不均衡的问题"，选择去优化大目标的分割降低损失值，而抛弃小目标的损失。其次是过拟合问题

​	(4).三个模型粘连问题都明显存在。Unet最严重，并且反而出现了类间混淆问题。
